# Day 33 – Simple Linear Regression

## 📌 Project Overview
This project demonstrates Simple Linear Regression using Python and Machine Learning.

The model predicts an employee's salary based on their years of work experience using a single input feature.

## 🎯 Objective
To build and understand a basic supervised machine learning regression model and predict numerical values.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## 📊 Dataset
A sample Salary vs Experience dataset was created with two columns:

- Experience – Years of work experience.
- Salary – Corresponding salary values.

## ⚙️ Steps Performed
1. Imported the required libraries.
2. Created and explored the dataset.
3. Checked for missing values.
4. Separated input features and target values.
5. Split the dataset into training and testing data.
6. Created a Linear Regression model.
7. Trained the model.
8. Generated predictions.
9. Evaluated model performance.
10. Visualized the regression line.
11. Predicted salary for new experience values.

## 📈 Model Evaluation
The model was evaluated using:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

### Results

| Metric | Result |
|---|---:|
| MAE | 0 |
| MSE | 0 |
| RMSE | 0 |
| R² Score | 1.0 |

**Prediction:** For 5 years of experience, the predicted salary is ₹45,000.

*Note: The perfect evaluation scores are due to the artificially created dataset having an exact linear relationship.*
